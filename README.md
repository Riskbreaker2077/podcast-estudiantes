# Podcasts estudiantiles — Lecciones para vivir

Sitio estático con los podcasts filosóficos producidos por estudiantes de 11-B a partir de *Lecciones de estoicismo*, de John Sellars.

## Contenido

- 9 episodios de audio en MP3.
- Una imagen por episodio.
- Un guion legible desde la página.
- Nombres de estudiantes, sin códigos.

## Desarrollo local

No requiere compilación ni dependencias. Sirve la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8000
```

Luego abre <http://localhost:8000>.

## Publicación

El sitio está preparado para GitHub Pages desde la rama `main`.
